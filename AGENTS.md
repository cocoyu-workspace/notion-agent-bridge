# Public distribution

This is the public, personal-deployment edition, notion-agent-bridge.
Keep the original license and attribution. Read README.md and AGENT_THREAD.md.
Work on named codex/ branches and deliver changes through pull requests.
Never push main/master directly. Never import the private development repository's history.
Users bring their own Notion account, AI entitlement, and login credentials.
Do not publish account pools, bulk registration, private environment scripts, credentials,
account files, logs, personal captures, or private repository changes without explicit authorization.
Preserve loopback-only defaults. Run focused Agent tests, go test ./..., frontend build,
Python launcher tests and Go build for runtime changes. Do not spend live account allowance
without authorization. No automatic synchronization from the private repository.

Git commit authors and committers must use a GitHub noreply email address.
Before publication, scan all reachable refs (including PR refs), commit metadata,
and documentation examples for personal email addresses and account identities.
Never copy actual account names, workspace identifiers, or login captures into examples.
